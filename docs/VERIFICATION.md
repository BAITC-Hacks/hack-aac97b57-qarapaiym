## Передача владельцам и следующие действия

1. **Владелец сборки / интеграции:** проверить `npm run build` на целевой машине. На этом macOS-хосте Turbopack падает с `Operation not permitted` при запуске CSS-процесса; `--webpack` проходит. Если ошибка повторится вне ограниченной среды, исправить команду сборки или конфигурацию.
2. **Владелец API:** живой AI-ответ сейчас на английском, хотя интерфейс переведён на русский. В одном ответе появилась рекомендация про долг и заимствования, отсутствующие в наборе данных; стоит уточнить языковое и фактологическое ограничение промпта. Контракт API и движок расчёта здесь не менялись.
3. **Владелец процесса / интеграции:** `AGENTS.md` сейчас содержит шаблоны игнорирования файлов вместо инструкций агентам. Это не блокирует показ, но может запутать дальнейшую работу с репозиторием.

AT-07 отмечен PASS после живого вызова провайдера, а не на основании подставного ответа теста. Для публичного платного API понадобится ограничение частоты запросов.
