## Границы подтверждения

- Тесты AI используют подставного провайдера. Чистый клон проверялся без API-ключа и не подтверждает доступность конкретной модели для другого аккаунта.
- README отражает имя модели из текущей конфигурации, не обещая её доступность каждому пользователю.
- Свободный AI-текст может содержать неверные числа даже при наличии фактов в запросе. Детерминированные таблицы остаются источником результатов; документация не объявляет эту проблему исправленной.
