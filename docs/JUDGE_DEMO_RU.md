# Показ для жюри: 60–90 секунд

Перед показом откройте приложение. Для живого AI-ответа настройте рабочий `OPENAI_API_KEY` на сервере; не показывайте содержимое `.env.local`. Если ключа нет, покажите понятную ошибку AI при сохранённом расчёте.

| Время | Действие и реплика |
| --- | --- |
| 0–10 с | Покажите стартовый экран: «У всех одинаковый виртуальный бюджет — 1 000 млн ₸ — и исходный AQoL 53,2. Данные демонстрационные». |
| 10–30 с | Выберите по одной инициативе: `transport-bus`, `greening-trees`, `social-clinics`, `safety-lighting`, `services-water`. Укажите на бюджет: 820 потрачено, 180 осталось. «Без пяти решений или при перерасходе запуск блокируется». |
| 30–45 с | Нажмите **Рассчитать сценарий**. Покажите AQoL **64,6**, прирост **+11,4** и таблицу «До / После / Изменение». «Числа рассчитаны кодом, AI их не вычисляет». |
| 45–60 с | Покажите AI-объяснение: резюме, сильные стороны, риски, компромиссы и рекомендации. Если ключа нет, покажите сообщение об ошибке и сохранённый расчёт. Не называйте подставной тестовый ответ реальным AI-вызовом. |
| 60–80 с | Сохраните A, выберите план B: `transport-junctions`, `greening-parks`, `social-outreach`, `safety-community`, `services-waste`. Запустите снова: расход **650**, AQoL **64,0**. Покажите сравнение: B дешевле на 170 млн ₸, но балл ниже на 0,6. |
| 80–90 с | Завершите: «Результат меняется вместе с решениями. Это инструмент изучения компромиссов на синтетических данных, а не прогноз для города». |

Если время ограничено 60 секундами, подготовьте сценарий A до начала отсчёта и в ходе показа запустите его, затем перейдите к сравнению с B. Обязательно объясните происхождение балла и покажите реальный статус AI.
