# Проверка нового раздела результатов

Дата: 2026-09-23. Реализовано на текущем контракте ветки `main` (база `ffff655`). Это **не** интеграция ещё отсутствующего официального ядра budget=100 / M1–M14.

## Что изменилось

Порядок: KPI → диаграммы Score и бюджета → сравнение направлений и районов → выбранные инициативы/эффекты → сохранённый A/B → четыре карточки AI.

- KPI: итог, изменение, расход/остаток, статус критических показателей, направления с лучшим изменением и наименьшим итогом. Ничьи показываются полностью.
- Четыре визуализации без новой библиотеки: парные полосы AQoL; расход/резерв; пять направлений до/после; пять районов, отсортированных по изменению.
- Инициативы: ID, направление, стоимость, фактический охват, диапазоны эффектов и раскрываемая детализация.
- AI: сильные стороны, риски, компромиссы, рекомендации; сначала до четырёх выводов и до трёх рекомендаций. Длинный текст и дополнительные пункты раскрываются, не теряются. Общий обзор убран в details.
- Сохранены выбор/сброс, сохранённый A, таблица районных метрик, retry и generation/abort guards. Ошибка AI не скрывает расчёт.

## Источник чисел и границы

KPI и диаграммы используют фактический `SimulationResult`. Расход, остаток, baseline, projected и общий delta не пересчитываются. Разности для сравнения и ширины полос — только представление этих данных.

Текущий контракт не экспортирует готовый районный Score. Для районной диаграммы повторно используется экспортированная `calculateSnapshot` на показателях каждого отдельного района; формула в UI не копируется. Подпись объясняет, что это среднее пяти показателей текущей модели. Это не утверждение об официальной формуле районного Score.

Критический порог, critical count, district/city scope выбора, синергии и атрибутированный вклад инициатив в общий Score в текущем ядре отсутствуют. Критические показатели помечены как нерассчитываемые; синергии — как незаданные. Вместо придуманной scope-привязки показан реальный охват impacts. Диапазоны эффектов явно не названы вкладом в AQoL.

AI-текст остаётся интерпретацией провайдера и может содержать неточности: новый layout не исправляет известную проблему свободного prose. Подтверждение происхождения чисел относится к KPI/диаграммам/таблицам, а не к достоверности всех утверждений AI. API и provider prompt этим редизайном не менялись.

## Проверки

Среда: Windows, переносимые Node 24.12.0 / npm 11.6.2.

- `npm test`: **PASS**, 4 файла, 34 теста, включая 7 новых presentation tests.
- `npm run typecheck`: **FAIL** — прежние TS2322 в `src/lib/data/index.ts:9` и пять TS18046 в `src/lib/data/validate.ts:40–43`. Ошибок в добавленных компонентах проверка не сообщила.

- Браузер: Edge через Playwright, 1440×1000 и 390×844, отдельный dev-сервер на 4389. **PASS**: сценарий 820/180 и AQoL 64.6; четыре визуализации; пять инициатив; сохранённое сравнение; смена решения очищает результат; AI failure сохраняет показатели; retry; отсутствие горизонтального переполнения страницы; reset; задержанный AI-ответ после смены выбора не возвращает старый разбор.
