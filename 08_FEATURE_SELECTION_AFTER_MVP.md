# Prompt — Judge Simulation

```text
Pretend you are a HackAlem judge with a clean computer.

Start only from README.md and the repository.

Do not use undocumented knowledge about the project.

Try to reproduce the official main scenario exactly.

Check:
- installation
- environment setup
- demo data/setup
- database setup/reset if applicable
- start command
- main flow
- error behavior
- tests
- build

Report only:
1. anything that blocks evaluation
2. anything that makes a mandatory requirement appear fake or incomplete
3. anything that could lose points under the official rubric

For each issue give:
- severity
- exact reproduction steps
- smallest reasonable fix
```
